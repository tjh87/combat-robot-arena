# Immediate tournament fights

## Start the next fight

1. Select **Fight now** to start your current bout.
2. After a win, select **Fight next round**.

These actions start the fight without a countdown. The next-round action immediately resolves unfinished AI-only bouts with a seeded bracket draw.

Completed results remain unchanged. Quick results show **Quick bracket result** in the match data.

Your robot retains its damage. The direct action spends no repair points and does not repair HP.

## Repair first

1. Select **Repair robot**.
2. Select your repair purchases.
3. Select **Commit & next round**.
4. Select **Fight now**.

The existing 900-point budget remains the same. The repair action also resolves unfinished AI-only bouts before it opens the workshop.

A completed player fight is necessary before a round advance. A loss returns the user to the arena without a wait.
