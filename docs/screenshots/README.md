# Screenshot provenance

Captured 25 September 2026 from the current source UI in a browser, using the real menu, builder, settings, photos and CSS. The browser could not create a WebGL context. A temporary capture fixture replaced only ArenaRenderer with no-op methods so the UI could load; no synthetic 3D scene was substituted. These are interface previews, not live gameplay or graphics-validation evidence.

The fixture and preview caches are excluded from the release and source commits. No gameplay source files or physics settings changed for the captures. The captures show the full interface viewport, with the unavailable 3D area explicitly labeled.
