# Complete offline Codex development package

- Full current game source, assets, tests and pinned dependency lockfile.
- Eleven stock robots with the latest Hydra assist, battery targets and physical gyro recovery.
- Local play, development, build and verification launchers.
- Included Windows x64 and Linux x64 Node runtimes and installed dependencies.
- Complete build prompt, continuation prompt, review prompt and feature prompt template.
- Current requirements, exact exported robot specifications, source map and testing instructions.
- Historical research and regression reports retained with clear precedence rules.

Extract the full ZIP. Run START-WINDOWS.cmd on Windows or `sh start.sh` on Linux x64.
Read handover/START_HERE.md before development.
The game and build tools run offline. The package does not include Codex or an AI model.
See the validation files for tested behavior and remaining Windows, graphics and sound checks.
